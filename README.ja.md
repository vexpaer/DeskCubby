## DeskCubby とは

DeskCubby は Android と Windows 向けの**ローカルファースト**な日記・パーソナルナレッジベースです。

- 日記、ノート、メディアは**実際のファイル** — 自分で選んだフォルダにある素の Markdown です。
- 小さなメモ、日付、詩、記録、進捗などの構造化データは端末内のデータベースに保存されます。
- 完全オフラインで動作。バックアップや複数端末が必要なときだけ、任意で WebDAV / S3 同期を利用できます。

## 主な機能

| | |
| --- | --- |
| **Markdown 日記** | テンプレート、食事カレンダー、写真記録、執筆統計を備えた日刊日記 — どこでも開ける素の `.md` ファイルとして保存。 |
| **ノートライブラリ** | 自分で選んだフォルダで管理する Obsidian 互換の Markdown ノート。プレビュー、リンク、メディア対応。 |
| **TXT / PDF リーダー** | 書籍の取り込み、中断位置からの正確な再開、全文検索、目次ジャンプ。 |
| **AI エージェント** | OpenAI 互換モデルとチャット。エージェントはネイティブなツール呼び出しで*あなたの*記録を検索・閲覧し、変更のたびに承認を求め、取り消し可能なレビューを残します。 |
| **記録キット** | 小さなメモ、大切な日付、日常記録、詩集、RSS 購読、パスワード保護の金庫、8 つのミニゲーム。 |
| **ホーム画面ウィジェット** | 日記・統計・ゲーム・クラウド同期用のリサイズ可能な Android ウィジェット — レイアウトも色もあなた次第。 |
| **カスタマイズ** | 3 つのビジュアルスタイル（Material、Liquid Glass、Organic Future）、ライト/ダークモード、カスタムテーマ、日中バイリンガル UI。 |
| **設計からプライバシー** | アカウント不要、テレメトリなし、クラウド強制なし。ファイルはあなたのフォルダに残り、同期は常にオプトインです。 |

## インストールと使い方

| プラットフォーム | 方法 |
| --- | --- |
| **Android** | [Releases](https://github.com/vexpaer/DeskCubby/releases/latest) から `DeskCubby.apk`（Android 8.0+）をダウンロードしてインストールします。案内が出たら「不明なアプリのインストール」を許可してください。アプリ内のアップデート確認で最新版を維持できます。 |
| **Windows** | [Releases](https://github.com/vexpaer/DeskCubby/releases/latest) からセットアップ版またはポータブル版をダウンロードします（Windows 10/11 x64）。 |
| **はじめに** | 日記用のフォルダを選び、最初の日記を書き、メモを残し、本を取り込みましょう。すべての記録はあなたが所有する実際の Markdown ファイルです。 |

> プラットフォーム補足: 内蔵ブラウザとホーム画面ウィジェットは Android 限定です。Windows は同等のコア体験を提供し、スマホ使用時間・健康データは表示のみで収集しません。
