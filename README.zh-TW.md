## DeskCubby 是什麼？

DeskCubby 是一款**本地優先**的日記與個人知識庫應用，同時支援 Android 與 Windows。

- 日記、筆記與媒體是**真實檔案**——你選擇的資料夾裡的純 Markdown。
- 小巧思、日期、詩詞、記錄與進度等結構化資料保存在本機資料庫。
- 完全離線可用；需要備份或多裝置存取時，可自願開啟 WebDAV / S3 同步。

## 核心功能

| | |
| --- | --- |
| **Markdown 日記** | 附模板、飲食月曆、照片記錄與寫作統計的每日日記——以純 `.md` 檔案保存，任何編輯器都能開啟。 |
| **筆記庫** | Obsidian 相容的 Markdown 筆記，按你自己的資料夾組織，支援預覽、連結與媒體。 |
| **TXT / PDF 閱讀** | 匯入書籍、精確續讀、全文搜尋並可從目錄跳轉。 |
| **AI Agent** | 與任意 OpenAI 相容模型對話。Agent 透過原生工具呼叫檢索與讀取*你的*記錄，每次修改前徵求同意，並保留可復原的 Review。 |
| **隨手記錄套件** | 小巧思、重要日期、日常記錄、詩詞本、RSS 訂閱、密碼保護的收藏夾與八款小遊戲。 |
| **桌面小卡片** | 日記、統計、遊戲與雲端同步的可縮放 Android 小卡片——版面與配色由你決定。 |
| **自由定制** | 三套視覺風格（Material、Liquid Glass、Organic Future）、明暗模式、自訂主題與中英雙語介面。 |
| **隱私優先** | 無需帳號、無遙測、不強制雲端。檔案留在你的資料夾裡，同步始終由你選擇。 |

## 安裝與使用

| 平台 | 方式 |
| --- | --- |
| **Android** | 從 [Releases](https://github.com/vexpaer/DeskCubby/releases/latest) 下載 `DeskCubby.apk`（Android 8.0+）並安裝，提示時允許「安裝未知應用」。應用內檢查更新讓您保持最新版本。 |
| **Windows** | 從 [Releases](https://github.com/vexpaer/DeskCubby/releases/latest) 下載安裝版或可攜版（Windows 10/11 x64）。 |
| **首次使用** | 選擇日記資料夾，寫下第一篇日記，記一條想法，匯入一本書。每一條記錄都是屬於你的真實 Markdown 檔案。 |

> 平台說明：內建瀏覽器與桌面小卡片僅限 Android。Windows 擁有完整的核心體驗，可查看手機使用時間 / 健康資料，但絕不採集。
