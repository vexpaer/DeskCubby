## DeskCubby 是什么？

DeskCubby 是一款**本地优先**的日记与个人知识库应用，同时支持 Android 与 Windows。

- 日记、笔记和媒体是**真实文件**——你选择的文件夹里的纯 Markdown。
- 小巧思、日期、诗词、记录与进度等结构化数据保存在本机数据库。
- 完全离线可用；需要备份或多设备访问时，可自愿开启 WebDAV / S3 同步。

## 核心功能

| | |
| --- | --- |
| **Markdown 日记** | 带模板、吃历、照片记录和写作统计的每日日记——以纯 `.md` 文件保存，任何编辑器都能打开。 |
| **笔记库** | Obsidian 兼容的 Markdown 笔记，按你自己的文件夹组织，支持预览、链接和媒体。 |
| **TXT / PDF 阅读** | 导入书籍、精确续读、全文搜索并可从目录跳转。 |
| **AI Agent** | 与任意 OpenAI 兼容模型对话。Agent 通过原生工具调用检索和读取*你的*记录，每次修改前征求同意，并保留可撤销的 Review。 |
| **随手记录套件** | 小巧思、重要日期、日常记录、诗词本、RSS 订阅、密码保护的收藏夹和八款小游戏。 |
| **桌面小卡片** | 日记、统计、游戏与云同步的可缩放 Android 小卡片——布局和配色由你决定。 |
| **自由定制** | 三套视觉风格（Material、Liquid Glass、Organic Future）、明暗模式、自定义主题与中英双语界面。 |
| **隐私优先** | 无需账号、无遥测、不强制云端。文件留在你的文件夹里，同步始终由你选择。 |

## 安装与使用

| 平台 | 方式 |
| --- | --- |
| **Android** | 从 [Releases](https://github.com/vexpaer/DeskCubby/releases/latest) 下载 `DeskCubby.apk`（Android 8.0+）并安装，提示时允许“安装未知应用”。应用内检查更新让你保持最新版本。 |
| **Windows** | 从 [Releases](https://github.com/vexpaer/DeskCubby/releases/latest) 下载安装版或便携版（Windows 10/11 x64）。 |
| **首次使用** | 选择日记文件夹，写下第一篇日记，记一条想法，导入一本书。每一条记录都是属于你的真实 Markdown 文件。 |

> 平台说明：内置浏览器与桌面小卡片仅限 Android。Windows 拥有完整的核心体验，可查看手机使用时间 / 健康数据，但绝不采集。
